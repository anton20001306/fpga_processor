## Nexys A7-100T FPGA Development Board

The Nexys A7-100T is a powerful FPGA development board from Digilent, based on the Xilinx Artix-7 XC7A100T FPGA. It is widely used for digital design, embedded systems, computer architecture, and FPGA-based prototyping. The board provides a rich set of peripherals, including switches, push buttons, LEDs, seven-segment displays, VGA output, USB-UART connectivity, and high-speed expansion interfaces, making it suitable for both educational and advanced development projects.

### Key Features
- Xilinx Artix-7 XC7A100T FPGA
- 15,850 logic slices and 4.86 Mb of block RAM
- 16 switches, 16 LEDs, and 5 push buttons
- Eight-digit seven-segment display


The Nexys A7-100T provides a versatile platform for implementing and testing digital systems, ranging from simple logic circuits to complex FPGA-based embedded applications.
